# Arvoresolidarialuizbertoli

Crie um site interativo chamado “Árvore de Natal Solidária 2026”, para uma campanha de arrecadação de doações em prol do Recanto Luiz Bertoli.

OBJETIVO:

Criar uma experiência natalina acolhedora, bonita e fácil de usar, que incentive as pessoas a conhecerem a campanha e contribuírem espontaneamente.

VISUAL:

- Uma árvore de Natal grande e centralizada, decorada com luzes e enfeites clicáveis.

- Design elegante, delicado e profissional, com cores natalinas harmoniosas.

- Uma breve apresentação da campanha e do Recanto Luiz Bertoli.

- Layout adaptável a celulares e computadores.

INTERATIVIDADE:

- Cada enfeite deve ser clicável.

- Ao clicar em um enfeite, abrir uma janela sobre a própria página com uma mensagem curta de Natal.

- A janela deve ter um espaço reservado para o QR Code Pix oficial e a chave Pix, além de um botão para copiar a chave.

- Incluir um botão para fechar a janela e voltar à árvore.

- Criar pelo menos seis enfeites com mensagens diferentes.

REGRAS IMPORTANTES:

- Não inventar chave Pix, QR Code, dados bancários nem informações institucionais.

- Usar espaços reservados para inserir os dados oficiais posteriormente.

- Não implementar cadastro de usuários nem coleta de dados pessoais.

- Não exigir pagamento dentro do site: a doação será feita pelo aplicativo bancário do doador.

- Utilizar hospedagem gratuita, se disponível, e não exigir servidor externo para a versão inicial.

Comece criando uma primeira versão funcional. Priorize a árvore, os enfeites clicáveis, as mensagens em janelas e a experiência no celular.
